# exam_AWS
Проєкт: Сервіс аналізу зображень

Опис

Веб-застосунок на ASP.NET Core MVC з використанням ML.NET для класифікації зображень, збереженням файлів у хмарі AWS S3 та записом історії аналізів у базу даних AWS RDS (SQL Server).

Перелік AWS-сервісів та технологій

Використав: ASP.NET Core MVC, ML.NET, Entity Framework Core

AWS S3 — для збереження завантажених зображень

AWS RDS (SQL Server) — для збереження історії розпізнавань

AWS IAM — для керування доступами та ключами

Публічне посилання

Link: (http://aiimageservice-linux.eba-sewdmgjx.eu-central-1.elasticbeanstalk.com/)
